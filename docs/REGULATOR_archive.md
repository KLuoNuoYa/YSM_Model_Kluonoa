## 文件 RG-A-001：项目立项与装备概述（摘要）

**项目名称：** REGULATOR  
**项目目标：** 研制具备全地形自主机动能力与区域压制火力的单兵综合作战平台，填补轻型无人平台与重型地面载具之间的任务空白。  
**成果型号：** PF-01A「PACIFIER」全地形动力突击外骨骼

**主要技术指标：**

| 项目 | 指标 |
|---|---|
| 动力与能源 | 高密度电源组，容量 200 kWh |
| 标准任务续航 | 8 h |
| 额定作业高度 | 800 m |
| 最大作业高度 | 9000 m |
| 机动系统 | 多向矢量推进，支持垂直起降、悬停及全向机动 |
| 轻型武器模块 | 7.62mm 转管机枪 ×2 |
| 重型武器模块 | 双联装 150mm 伸缩式火炮 ×1 组（配"Turnkey"展开机构） |
| 运算系统 | 高规格机载运算副核，飞控/火控一体化 |
| 收纳 | 模块化折叠，非展开状态可缩减至背负级尺寸 |

**生产情况：** 试生产三批次（LOT 01–03），共 ██ 台，全部用于测试、评估与训练，未列装作战部队。

## 文件 RG-C-014：项目终止评估报告（结论摘要）

**评估结论要点：**

1. 单台采购成本为预算原案的 ███%，维护与备件体系成本不可控；
2. 火力维度无法替代重型平台，成本维度无法竞争无人平台，任务定位存在结构性矛盾；
3. 重型武器模块与机动平台互为负载设计，无法通过裁剪武器的方式衍生低成本型号；
4. 更新一代单兵机动平台已列入发展规划；
5. 建议：终止项目，不转入正式量产。

**批示：** 同意。项目终止，后续处置另行发文。

## 文件 RG-RA-041：关于 RG-PF01A-L03-017 的风险评估与处置建议

**密级：** 内部资料 · 限阅  
**评估对象：** RG-PF01A-L03-017（PF-01A PACIFIER）

### 一、现状评估

1. 该装备现由一名平民持有者使用，已完成大规模民用改装；
2. 经持续观察确认：**原始武器模块（双 7.62mm 转管机枪、双联 150mm 火炮）已被持有者自行拆除并脱离机体**；
3. 持有者不具备、亦未表现出恢复武器系统的意图。

### 二、风险评估

1. **火力风险：已消除。** 该装备的核心火力已被剥离。推进系统因失去武器负载而动力过剩，但不构成威胁属性——一台飞得更快的送货装置仍是送货装置；
2. **滥用风险：低。** 持有者的"私拆乱改"在客观上完成了我方未能完成的去武装化，该残件被用于暴恐活动的可能性可忽略；
3. **曝光风险：低。** 在民间，旧型号外骨骼流入二手市场已非新闻。该装备被普遍视为某种"前卫的个人工程机械"，未察觉其军用背景。持有者本人亦表现出刻意的低调倾向；
4. **泄密风险：可控。** 敏感敌我识别与加密组件已在转移前依规处置；机载记录仪仅含资产台账事件记录，无技术价值。残余技术外泄价值有限。

### 三、处置方案比选

| 方案 | 评估 |
|---|---|
| 强制收缴 | **不可行。** 从平民手中收缴一台"机甲"必然引发舆论关注，资产流失的行政错误将随之曝光，处置成本远高于装备残值 |
| 协商回购 | 存在接触暴露风险，且回购行为本身即构成对资产流失事实的书面确认 |
| 核销并监控 | **建议采纳。** 在系统内将该资产直接核销，终止其军方资产身份；同时通过技术手段保持长期低强度监控 |

### 四、技术措施建议

该型装备出厂时于**动力骨架一体成型结构内部**封装有休眠追踪模块，属防遗失设计，不依赖机载电源，无外部接口。

持有者历次改装均未触及骨架本体结构，该模块完好。

建议远程激活，转入静默监控。

### 五、结论

**建议：核销 RG-PF01A-L03-017，激活休眠追踪模块，长期监控，不接触、不干预。**
