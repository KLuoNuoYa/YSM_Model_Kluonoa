# 一、军方正式命名与编号体系

### 1. 装备名称

**PF-01A Pacifier**

Pacifier 是该装备在军方采购与装备管理体系中的正式名称。

其命名并非来自某一种特定武器，而是强调装备在复杂环境下快速部署、机动控制和压制危险目标的综合能力。

PF 是 Powered Frame（动力骨架）的型号类别缩写。

01 表示该系列的第一代基础型号。

A 表示初始定型配置。

因此，本机的完整型号为：

**PF-01A Pacifier**

中文正式名称：

**PF-01A 型平定者全地形动力突击外骨骼**

### 2. 军方资产编号

为了装备管理的规范性，采用项目代码、型号、生产批次和独立序列号组成完整编号。

本机档案采用以下编号：

| 编号项目 | 内容 |
|---|---|
| 项目代号 | REGULATOR |
| 装备型号 | PF-01A |
| 装备名称 | PACIFIER |
| 生产批次 | LOT 03 |
| 独立序列号 | SN-017 |
| 完整资产编号 | RG-PF01A-L03-017 |

其中：

- RG：REGULATOR 项目识别码。
- PF01A：装备型号。
- L03：第三（也是最后一个）试生产批次。
- 017：该批次中的第 17 号装备。

这意味着小螺获得的并不是一台普通的民用仿制品，而是一台具有独立军方资产身份的原始装备。

### 3. 关于生产规模

REGULATOR 项目未能进入正式量产，在低速率试生产阶段即被终止。

三个试产批次（LOT 01–03）共制造了数十台装备，全部用于测试、评估与训练，从未列装作战部队。

这也是"平定者"鲜为人知的原因之一：它存在过，留下了资产档案，但从未真正服役。

### 4. 装备铭牌

原始铭牌采用以下格式：

```text

PF-01A PACIFIER

ALL-TERRAIN POWERED ASSAULT FRAME

LOT: 03
S/N: 017

PROPERTY OF DEFENSE PROCUREMENT
CONTROLLED EQUIPMENT
```

经过小螺改造后，原始铭牌仍然保留在机体内部，没有被完全拆除。

# 二、原始设计：全地形动力突击平台

PF-01A 的设计理念是将高机动性与强大直接火力整合在同一套个人化装备中。

它并非传统意义上单纯强化人体力量的外骨骼，而是一套具有独立动力、推进和武器系统的综合作战平台。

其最显著的特点是：

**不依赖传统地面载具，也能够在复杂地形中实现快速机动，并在抵达目标区域后立即投入任务。**

### 1. 全地形机动系统

装备采用多向矢量推进器作为主要机动系统。

通过分布在机体不同位置的推进单元协同工作，可以实现：

- 垂直起降。
- 空中悬停。
- 水平高速移动。
- 复杂姿态调整。
- 狭小空间内的方向转换。
- 不规则地形上的快速跨越。

与依赖大型固定翼面的传统飞行装备不同，PF-01A 更强调个人化的全方向机动能力。

机械翼不仅承担辅助飞行和姿态稳定功能，也集成了能源采集与其他辅助设备。

### 2. 主要攻击模块

PF-01A 原始配置中最具代表性的部分，是两套直接火力系统。

**A. 双 7.62mm 转管机枪**

原始配置中的轻型持续火力模块，共两挺。

主要用途是对地面目标提供持续火力压制。

其特点是射速高、持续输出能力强，与外骨骼的高机动特性相结合，可以在移动过程中维持火力覆盖。

**B. 双联装 150mm 伸缩式巨炮**

原始配置中的重型直接火力模块。

采用双联装结构，炮管能够在非使用状态下进行伸缩收纳，以降低装备整体展开尺寸。

在需要使用时，炮管展开并进入工作状态。

这套系统具有极强的直接火力，主要用于攻击高防护目标以及破坏坚固障碍物。

它与转管机枪形成明显的轻重火力组合：

- 转管机枪负责持续火力输出。
- 双联巨炮负责重型目标打击。

两套武器均为外置模块化挂舱，与动力骨架本体结构相对独立。

### 3. 开火模式：火力与机动的共存方案

将载具级火力整合进单兵平台，最大的工程难题是**后坐力**。

REGULATOR 项目的解决方案是两套截然不同的开火模式：

**机动作战模式**

矢量推进器全功率运行，机体处于悬停或机动状态，使用双 7.62mm 转管机枪。

机枪开火时，推进器根据射击轴线实时输出反向补偿推力以抵消后坐。

这一功能要求飞控与火控进行毫秒级数据交换，也是 PF-01A 配备高规格运算副核的根本原因。

**展开炮击模式**

使用 150mm 巨炮前，机体必须降落并进入展开状态：

- 腿部结构锁定。
- 足部锚钉展开并固定于地面。
- 背部炮组展开、炮管伸出。
- 推进器转入辅助稳定模式。

整套展开动作由代号为 **"Turnkey"** 的部署机构完成。

在此状态下，整台外骨骼实质上成为一座人形炮位，由骨架、锚钉与地面共同承担后坐。

150mm 炮无法在飞行或移动中开火，这既是物理限制，也是原始设计中的明确使用规范。


### 4. 模块化结构

PF-01A 采用模块化设计。

动力骨架、推进器、机械翼、武器挂舱和辅助设备均具有相对独立的结构。

这种设计便于维修、更换和任务配置，也为后来的民用改造提供了便利。

值得一提的是，动力骨架本体为**一体成型结构**，不具备无损拆解手段——这个工程决策在多年以后，将以一种出人意料的方式证明其价值。

此外，作为军方受控资产，PF-01A 标配独立的**服役事件记录仪**：一枚与作战系统物理隔离的资产管理芯片，只记录装备全寿命周期的履历事件——出厂、测试、封存、转移、处置登记。它相当于这台装备的电子履历本，也是多年以后小螺得以窥见它前世的主要窗口。

# 三、时代背景、项目终止与装备流失

在讲述这台装备的流失之前，需要先交代它所处的时代。

在小螺生活的年代，动力外骨骼技术早已度过保密期，进入了**技术扩散期**。

军用型号经历多轮迭代，现役装备的性能已明显超越 PF-01 这一代产品。与此同时，退役的、试产的、项目终止的旧款装备，正沿着资产处置、承包商转售、二手交易的链条持续流入民间——就像总有人能在新主机发售前弄到工程主板一样，二手市场上出现一台旧型号外骨骼，算不上什么新闻。

PF-01A 问世时是不折不扣的尖端产品；但等它挂上二手平台时，已经只是一台**过时的老旗舰**——性能依旧强悍，只是不再稀罕。

REGULATOR 项目就终止于这样的时代背景之下。

项目在试生产与评估过程中逐渐暴露出过高的生产与维护成本。复杂的动力系统、专用零件以及高能耗武器模块，使其难以满足军方后续的大规模采购需求。

与此同时，军方对装备采购方向进行了调整，更新一代的单兵机动平台已列入发展规划，REGULATOR 项目最终被决定终止。

项目结束后，已经制造的全部 PF-01 系列装备被列入资产处置计划。

本机原定处理方式为内部拆解销毁。

但在一次军方内部行政指令更新过程中，资产处置部门错误地沿用了旧版转运命令。

原本应该运往内部销毁设施的装备，被错误地登记为可转移的项目剩余资产。

随后，这批装备被转交给了参与 REGULATOR 项目的私人承包商——联合重工。

私人承包商在接收时依据的是已经批准的资产转移文件，并未意识到这批装备实际上仍处于内部销毁名单之中。

最终，PF-01A SN-017 成为一件具有合法转移记录、但不符合原始处置意图的特殊库存资产。

承包商没有能力继续维护这类装备，也不愿意承担高昂的维护成本。

于是，它被作为项目剩余设备长期存放，最终进入库存清理流程。

值得一提的是，在那个旧款机电装备随处流通的年代，一台来路模糊的外骨骼出现在清理清单上，并没有引起任何经手人的特别注意。

这就是本机流入民间的直接原因。

# 四、小螺获得 PF-01A

小螺最初并不知道这套装备的完整历史。

她是在一次私人承包商的库存清理活动中发现它的。

当时的 PF-01A 已处于长期低维护状态：能源系统亏电，原始控制系统存在一些兼容性问题，部分外部饰板与传感器缺失。

但动力骨架、推进系统、武器挂舱和核心 AI 副核仍然保存完整——包括供弹机构内剩余的弹药。

小螺最初的采购计划是拆解这台装备，回收其中有价值的能源模块、机械组件和计算设备。

但在进行初步检查时，她发现这台设备的 AI 副核仍然能够正常启动。

进一步检查还发现，副核中保存着大量原始项目数据。

这让她改变了计划。

她决定暂时停止拆解，先尝试恢复设备的运行能力。

随着维修工作的推进，她逐渐发现这台外骨骼远比自己最初想象的更有价值。

最终，她决定保留整套装备，并开始按照自己的需求进行改造。

---

# 五、民用改造：从 Pacifier 到 Skypatrol Frame

小螺并没有试图恢复 PF-01A 的原始战斗配置。

相反，她认为原始设计中的攻击模块已经不适合自己的使用需求。

于是，她对装备进行了较为彻底的功能调整。

### 1. 攻击模块拆解

小螺首先处理的是原始武器系统。

双 7.62mm 转管机枪和双联装 150mm 伸缩式巨炮均被拆解。

拆解工作不仅涉及武器本体，也包括相关的供弹、驱动、火控和控制组件。

剩余弹药被单独退出并安全封存——这是整个改装工程中她最谨慎对待的环节。

原有的武器挂载位置被重新整理，部分接口被改造成通用设备安装位。

原始火控系统被移除或解除连接。

经过这次改造，装备不再具备原始武器系统的完整工作能力。

不过，诊断档案中仍保留着原始武器系统的登记条目，因此系统自检时仍会列出这些已拆除组件的状态信息。

### 2. 受力结构重新校准

原始受力结构按军方标准体型设计，与小螺 157cm 的体格严重不匹配。

她对骨架的承重分布、关节行程和推进器安装角度进行了全面重新校准——

这是整套改装中工作量最大的部分，也是这台装备真正"成为她的装备"的标志。

### 3. 多向矢量推进系统

推进系统是小螺决定完整保留的核心组件。

她重新调整了推进器的控制逻辑，使其更加适合个人日常使用。

改造重点包括：

- 改善悬停稳定性。
- 优化低速移动控制。
- 提高狭小空间内的机动能力。
- 降低非必要能源消耗。
- 增加与个人设备之间的协同能力。

武器模块拆除后，原本用于后座补偿的推力余量被重新分配，民用状态下的机动性能反而优于原始设计指标。

### 4. 机械翼

原始机械翼结构被保留，但部分内部组件经过重新整理。

机械翼除了辅助机动，还承担太阳能辅助供电、姿态稳定和辅助传感器安装等功能。

它也成为整套装备最具有视觉辨识度的结构之一。

### 5. AI 副核

原始 AI 副核被完整保留。

小螺为它重新配置了民用操作权限，并逐步修改了原始任务管理逻辑。

新增功能包括：

- 日常导航。
- 环境监测。
- 飞行辅助。
- 工程计算。
- 设备状态诊断。
- 能源管理。
- 外接设备协调。

原始军事任务程序中已经失去用途的部分被禁用。

不过，AI 副核仍然保留着一些原始系统数据和历史记录——包括一套语气温柔、内容骇人的原始作战语音包。

### 6. 能源系统

原始能源系统经过重新校准。

小螺将装备的能源调度逻辑改为以持续运行和多用途辅助为主要目标。

同时增添了与小螺本体之间的双向充电能力。

### 7. 外观调整

小螺没有完全改变原始装备的结构风格。

她保留了动力骨架、推进器、机械翼和部分装甲组件。

但外部装甲、设备接口和辅助组件逐渐被替换为符合自己审美的蓝白色设计。

最终形成了现在的御天巡逻者外观。

# 六、名称变更：御天巡逻者

完成初步改造后，小螺和她的朋友开始讨论是否应该给这套装备取一个新名字。

继续使用 Pacifier 显然不太合适。

一方面，这个名字带有明显的军方背景；另一方面，现在的装备已经失去了原始攻击系统，其使用目的也发生了根本变化。

最终，决定将它命名为：

**Skypatrol Frame**

中文名称：

**御天巡逻者**

这个名称不再强调装备的军事属性，而是强调它的高空机动、探索和辅助能力。

从此，这套装备拥有了两个不同的身份：

| 项目 | 原始身份 | 民用身份 |
|---|---|---|
| 名称 | Pacifier | Skypatrol Frame |
| 中文名称 | 平定者 | 御天巡逻者 |
| 型号 | PF-01A | SPF-C01（民用改造标识） |
| 主要用途 | 全地形突击 | 多用途机动辅助 |
| 武器系统 | 双转管机枪、双联重炮 | 已拆解 |
| 推进系统 | 多向矢量推进 | 保留并改进 |
| AI 系统 | 军用辅助副核 | 私人辅助系统 |
| 所有权 | 军方项目资产 | 小螺私人持有 |

其中，SPF-C01 并不意味着原始军方型号被正式注销，而是小螺自己使用的民用改造版本标识。

原始军方编号 RG-PF01A-L03-017 仍然保留在设备档案中。

# 七、遗留问题：仍然存在的军工痕迹

虽然御天巡逻者已经完成民用改造，但它并没有完全摆脱原始 PF-01A 的身份。

### 1. 原始装备档案

设备内部仍然保留着原始项目编号和部分资产信息。

某些系统在启动时，仍会显示原始装备名称。

例如：

```text
PF-01A PACIFIER

ASSET STATUS: WRITTEN OFF
```

### 2. 已拆解武器的系统记录

诊断档案中仍保留着原始武器系统的登记条目。

当小螺检查相关接口时，系统会显示：

```text
WEAPON SYSTEM DIAGNOSTICS

2x 7.62mm MINIGUN
STATUS: NOT INSTALLED

DUAL 150mm TELESCOPIC GRAND CANNON
STATUS: NOT INSTALLED

TURNKEY DEPLOYMENT SYSTEM
STATUS: REMOVED

FIRE CONTROL SYSTEM
STATUS: DISABLED
```

这些信息并不代表武器仍然能够使用，而只是原始设备档案尚未完全更新。

### 3. 原始 AI 副核与服役事件记录仪

副核中仍然保留着部分军用项目数据。

小螺并没有完全删除这些数据，因为它们可能对维修、系统优化和设备历史研究具有价值。

服役事件记录仪同样原样保留。由于它与作战系统物理隔离，武器拆除与权限改造均未触及——小螺对这台机器前世的大部分了解，正是来自这枚小小的台账芯片。

而且，她也逐渐习惯了这个原本属于军工装备的辅助系统。

### 4. 资产处置记录

从军方原始档案来看，PF-01A SN-017 的处置流程曾经长期悬而未决。

而如今，它的档案状态是：**WRITTEN OFF（已核销）**。

在军方的数据库里，这台装备已经正式不存在了。

小螺对此一无所知。她只知道，自己买它的手续齐全、来历清白，这么多年也从没有人找上门来——

她把这归结为运气好。

### 5. 她没找到的东西

小螺的改装几乎触及了这台装备的每一个角落：

武器舱、供弹机构、火控、能源、推进控制、副核权限……

除了动力骨架本体——那是一体成型的，没有拆的理由，也没有拆的手段。

出厂时封装在骨架深处的休眠追踪模块，此刻仍在以极低的功耗，向某个她不知道存在的方向，定期汇报着四个字：

**无异常。**

# 八、最终设定摘要

PF-01A Pacifier（平定者）是一款由 REGULATOR 项目研发的军用全地形动力突击外骨骼。

它拥有多向矢量推进系统、机械翼、双 7.62mm 转管机枪和双联装 150mm 伸缩式巨炮，能够在复杂环境下实现高速机动与强大直接火力输出。

它诞生于动力外骨骼技术的扩散期：问世时是尖端产品，但项目于试生产阶段即告终止，流入民间时已属上一代的老旗舰。

原本应该进入内部销毁程序的 PF-01A SN-017，因为军方内部行政指令执行错误，被转交给私人承包商，最终在那个旧款装备随处流通的年代里，悄无声息地挂上了二手交易平台。

小螺最初打算拆解其中的零件，但在发现核心 AI 副核仍然能够运行后，决定保留整套装备。

她拆除了原始武器系统，按自己的体格重新校准了受力结构，重新调整了推进器、能源管理和 AI 副核，并将装备改造成自己的私人多用途平台。

最后，她和朋友为这套装备取了一个新的名字：

**Skypatrol Frame——御天巡逻者。**

它曾经是一台名为平定者的军用突击外骨骼。

现在，它只是小螺自己的装备。

——至少，她是这么认为的。
