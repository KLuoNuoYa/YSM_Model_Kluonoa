# 御天巡逻者 · 整理笔记
## 小螺的私人工作日志 · 副核数据恢复记录

整理了很久，把能从副核里恢复的资料和我自己的改装记录放在一起存个档。
有些部分数据损坏严重，只能空着——要是哪天又恢复出新的内容，再补上的咕。

---

## 一、它原本的名字

这台机器里其实有两套互不相干的存储：
- **副核**：是飞控/火控计算机，同时用于保存技术手册、图纸、EVA这些"干活用的"东西；
- **服役事件记录仪**：军方给每件受控资产标配的电子台账芯片，与作战系统物理隔离，
  只记录这台装备经历过什么——出厂、测试、封存、转移、处置登记……
  相当于飞机的履历本,但只包含事件条目，没有文件原文。
- 也正因为记录仪和作战系统完全独立，我在拆除武器，修改权限的时候一点都没碰到它。

【以下恢复自记录仪 · 装备档案区，完整度约 87%】

这台机器的军方正式名称是 **PF-01A Pacifier**，中文叫"平定者"。

- 项目代号：REGULATOR
- 装备型号：PF-01A（Powered Frame，第一代基础型，初始定型配置）
- 资产编号：**RG-PF01A-L03-017**（第三试产批次，第 17 号机）
- 性质：军用全地形动力突击外骨骼

这个项目从头到尾只活了三个试产批次，
几十台机器全部用于测试和评估，**一天正式服役都没有过**。

至于"PACIFIER"这个名字……我查过词典的咕。
这个词除了"平定者"，在日常生活中更常见的意思是——**安抚奶嘴**。

更离谱的是副核里还存着一整套**原始作战语音包**。我试听了几条：

*"Nothing to worry about."*
*"They will comply."*
*"We'll put them to rest."*

……全程用哄人的语气，播报的全是炮击指令。

语音库的版本签名显示，这套系统代号 EVA——Electronic Video Agent，电子视频助手。
也不知道是哪一代传承下来的命名，反正比"奶嘴"像话一点的咕。

给一台背着双联 150mm 巨炮的机器起名叫"奶嘴"，再配上一套哄睡一样的语音。
军工部门的幽默感，我是彻底理解不了的咕。

骨架内侧还有一块原始铭牌，编号被打磨过，但能勉强看清：

```text
MILITARY EQUIPMENT
REGULATOR PROGRAM
PF-01A PACIFIER
ALL-TERRAIN POWERED ASSAULT FRAME
LOT: 03
S/N: 017
PROPERTY OF DEFENSE PROCUREMENT
CONTROLLED EQUIPMENT
```

我把这个保留了。磨掉名字这种事，做过一次就够了。

## 二、它原本是什么

【恢复自副核 · 技术手册分区，完整度约 92%】

### 机动系统

多向矢量推进，全向机动：垂直起降、悬停、高速飞行、狭小空间转向。
机翼负责辅助飞行和姿态稳定，表面有太阳能晶片——
这套东西完好率高得吓人，也是我后来决定把它留下来的主要原因。

### 武器系统（已拆除，图纸存档）

原始配置有两套直接火力：

1. **双 7.62mm 转管机枪**：机动状态使用，持续压制火力；
2. **双联装 150mm 伸缩式巨炮**：重型攻坚火力，炮管可伸缩收纳。

手册里关于开火模式的部分是这样说明的：

- 启用机枪时，推进器要**实时输出反向推力抵消后坐**——飞控和火控是毫秒级联动的，
  所以这台机器才需要那么夸张的运算副核；
- 启用 150mm 炮时，机器必须**落地、锁定腿部、足部锚钉固定**，
  整台外骨骼变成一座炮位。这套展开机构在手册里叫 **"Turnkey"**。

也就是说，展开炮击的时候，穿戴者本质上只是火炮炮架的咕。
设计这个东西的人，到底把里面的人当成什么了啊……

### 结构

全模块化设计，武器挂舱、推进器、机翼都能独立拆换——
托这个设计的福，我的改装省了很多事。

唯一拆不了的是动力骨架本体：**一体成型，没有任何无损拆解的手段**。
清理内部的时候我只能绕开它，好在骨架本身也不需要维护。

## 三、来历考据（不完整）

【恢复自记录仪 · 资产台账区，**完整度约 41%，多处损坏**】

这一部分缺得很厉害。记录仪只记事件、不存原文，
我能看到的只有一条条没头没尾的台账记录。把完整度还行的部分摘出来：

```text
[LOG_0001] 出厂检验通过。经办：LOT03 产线。
[LOG_0014] 移交军方试飞中心。状态：全新。
[LOG_0082] 试飞测试：第104次。备注：机体结构完好，试飞员软组织挫伤。
[LOG_0104] 暂缓测试。原因：项目预算超支。
[LOG_0119] 资产封存。地点：███地下仓库。
[LOG_0120] 资产处置指令下达：内部销毁。
[LOG_0121] 转运出库。接收方：联合重工（承包商）。
[LOG_0122] 状态更新：废旧机电设备。
[LOG_0123] 系统重启。检测到电源接入。
```

**LOG_0120 和 LOG_0121 是互相矛盾的。** 销毁指令下达之后，
  机器却作为"废旧机电设备"转运出库，接收方还是参与项目的承包商。
  中间到底发生了什么，对应区段恰好全部损坏——
  有时候我会怀疑这个"恰好"，但记录仪不会回答我的咕。

承包商那边倒是毫无戏剧性：他们一直以为自己处理的是普通报废设备。
从他们的角度看，手续齐全、账物相符，挑不出任何毛病。

尽管现在这个年代，旧款外骨骼出现在二手市场上本来不算什么新鲜事。
技术迭代了好几轮，淘汰下来的旧型号沿着各种灰色链条到处流。
PF-01A 刚问世的时候也许是尖端货，但我买到它的时候，
它已经只是一台过时的老旗舰了——性能依旧强悍，只是不再稀罕。

至于为什么这么多年没人来追查这批装备……
档案到这里就真的什么都不剩了。

## 四、我是怎么买到它的

在承包商的库存清理里发现它的时候，状态很糟：能源亏电、控制系统有兼容问题、
外部饰板缺了几块。骨架和推进器看上去状态还算可以。

本来只想拆了当备件。通电测试那天，内置副核居然正常启动了，
里面存着几乎完整的项目资料。

然后我就改主意了的咕。

## 五、改装记录

### 1. 武器拆除（最先做的一件事）

两挺机枪、双联 150mm 炮组、供弹机构、火控，全部拆除。
余弹单独退出封存——为什么里面会有实弹，我也没弄明白的咕。

原来的武器挂点改造成了通用设备接口，现在安装的是传感器和防护装备。

诊断档案里还留着武器系统的登记条目，所以自检时永远会显示：

```text
WEAPON SYSTEM DIAGNOSTICS

2x 7.62mm MINIGUN
STATUS: NOT INSTALLED

DUAL 150mm TELESCOPIC GRAND CANNON
STATUS: NOT INSTALLED

TURNKEY DEPLOYMENT SYSTEM
STATUS: REMOVED

FIRE CONTROL SYSTEM
STATUS: DISABLED
```

每次看到都想说：不用提醒了，是我拆的咕。

### 2. 受力结构校准（工作量最大的一件事）

原始结构按军方标准体型设计，和我 157cm 的体格完全不匹配。
承重分布、关节行程、推进器安装角度全部重新校准。

### 3. 推进系统

完整保留，重写了控制逻辑，操作手感好了不少。

武器拆掉以后，原本用来抵消后坐的推力余量全空出来了——
它现在比军方设计指标上写的还能飞。这件事我没有到处说的咕。

### 4. 机翼

完整保留，内部重整。现在兼顾太阳能充电、姿态稳定和传感器平台。

### 5. 副核

完整保留，军事任务程序里用不上的部分禁用了，
但原始数据没删——修机器要用，而且……里面毕竟是它的前世。

### 6. 能源

重新校准能源调度，增添双向充电功能。
它电量低的时候能用太阳能发电，我电量低的时候它能给我充电。
续航焦虑是什么？不认识的咕。

### 7. 外观

骨架、推进器、机翼原样保留，外部装甲换成了蓝白色。
现在的涂装是第二次迭代，比较满意，暂时不改了。

完美。

## 七、还没弄明白的事

有待调查：

1. **销毁令为什么没有执行。** 档案在关键处损坏，可能永远缺着这几页了；
2. **其他几十台同型机的下落。** 记录显示整个批次都被"外包处置"了。
   我只买到了 017。其他的……在冶炼厂的概率比较大吧。应该是吧；
3. **启动画面里的最后那行字。** 每次开机都会闪过：

   ```text
   EVA SYSTEM READY
   Establishing battlefield control, standby...

   PF-01A PACIFIER
   ASSET STATUS: DISPOSAL PENDING
   ```

   "待处置"。也就是说在军方数据库里，它可能仍然是一台**等待销毁**的机器。
   这条状态存在记录仪中，只在接入军方资产系统时才会更新——
   它最后一次同步，应该还是很多年前躺在军方库房的时候。
   至于后来有没有变成别的状态，我无从查起……
   反正真有人敲门的话，到时候再想办法的咕；
4. **副核深处的加密区。** 还有一块区域一直没解开。
   拆别人的日记不太好，但我确实有点好奇。

## 八、后记

它曾经是军方的"平定者"，等着去平定什么东西。

现在它叫御天巡逻者，是全市最快的外卖自提架，
顺便是我的移动工位、充电宝和（偶尔）保镖。

档案里它的前世冷冰冰的。但我觉得吧——

装备的命运不是出厂那天定的，是拆开武器舱那天定的咕。
